# Remote PowerShell Attacks via WinRM
This repository contains our weekly Cyber Threat Intelligence course project. We study how PowerShell Remoting via WinRM can be abused and how such activity can be investigated.

## AI Usage

We used ChatGPT as an assistant while preparing the project materials. Its role differed across the three weeks:
- Week 1 — Cyber Threat Intelligence Fundamentals: ChatGPT helped us draft explanations of terms specific to PowerShell Remoting via WinRM, and improve the English wording of the threat classification.
- Week 2 — Data Collection Process: ChatGPT helped us plan open-source searches, organize the data source map, and describe how each source contributed to the analysis. We recorded the original source of every finding in the Week 2 report.
- Week 3 — Data Processing and Exploitation:ChatGPT helped us plan the filtering and normalization steps, understand how to document the MISP import, and edit the explanation of our results.
